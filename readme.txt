Design printed badges for your event's attendees and get a PDF ready for the print shop.

== Description ==

CampTix Badge Designer turns your CampTix attendee list into printed badges, the way data merge works in a desktop publishing program.

1. Design the badge background in any drawing program (PDF, PNG or JPG) and upload it to the Media Library.
2. In Tickets > Badge Designer, place the attendee fields over it: text boxes with the first name, the last name or the event's own questions, the attendee's Gravatar, and a QR code that links to their WordPress.org profile.
3. Step through the attendees to check long names, missing photos and missing usernames.
4. Generate one PDF page per attendee, for all of them or a range, with bleed and crop marks, ready for the print shop.

Features:

* Visual editor in the WordPress admin, saved automatically, with undo.
* Any print size; 100 × 150 mm with 3 mm bleed by default.
* Single badges, or badges to fold in half: you design one side, and each page gets it twice, the top one upside down.
* A vector PDF background stays vector in the final PDF.
* Text in Inter, included, or any font installed with the WordPress Font Library, in the colors of your site's palette.
* Text that does not fit shrinks a little; if it still does not fit, it is cut with an ellipsis and listed, so it can be checked before printing.
* A mark for the lanyard hole, on by default: a small line at the top center to help punch the hole.
* Print only the attendees with a CampTix admin flag, for example the volunteers.
* Gravatars round or square, with a fallback: nothing, an image generated by Gravatar, or your own image.
* The PDF is made in your browser: nothing is generated or stored on the server.
* The design can be exported and imported, to reuse it on next year's site.

== Privacy ==

* Attendee email addresses never leave the server: the editor receives a SHA-256 hash of each address, as Gravatar requires. On WordCamp.org, it also receives the hash of the attendee's WordPress.org account address, used when the ticket address has no Gravatar.
* To show and print Gravatars, your browser requests the images from gravatar.com with those hashes. See the Gravatar privacy policy: https://automattic.com/privacy/
* The plugin stores only the badge design, in the `ctbd_design` option, which is deleted when the plugin is uninstalled.

== Frequently Asked Questions ==

= Where does the attendee list come from? =

From CampTix, live, when it is active on the site: only paid tickets get a badge, in purchase order, and activity tickets (such as Contributor Day) get none of their own. The editor is then under Tickets > Badge Designer. On a development site without CampTix, from a CampTix CSV export placed in the plugin's `test-data` folder.

= Why do some badges have no QR code? =

The QR code links to the attendee's WordPress.org profile, so it needs their WordPress.org username. Tickets without a valid username get no QR code; the Generate PDF dialog says how many.

= What happens with names that do not fit? =

Text shrinks to 80% of its size at most. If it still does not fit, it is cut after the last whole letter and ends with an ellipsis (…). The editor marks it and the Attendees panel lists who is affected.
