# Status

Milestones 0 to 7 are done: a visual badge editor in the WordPress admin, with a background from the Media Library, text boxes with attendee data and ticket questions, Gravatars and QR codes to WordPress.org profiles, and the badges PDF generated in the browser, with bleed and crop marks. Attendees come from a CampTix CSV export.

The plugin was renamed from Camptix Badge Generator to CampTix Badge Designer (slug `camptix-badge-designer`, prefix `ctbd`), because WordCamp.org already runs a plugin with the old name. The goal is to propose it to WordCamp.org as the replacement for the Canva export in PR WordPress/wordcamp.org#2278 (see `docs/decisions.md`).

Next: milestone 8, a Playground sandbox with the real CampTix and the attendees read live, waiting for Nilo's OK. Then a public demo and the proposal upstream (milestone 9).
